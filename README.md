# Hangman-game

Консольная игра «Виселица», написанная на Python.

## Описание проекта

Проект разрабатывается в рамках учебной работы
по демонстрации Scrum-процесса разработки программного обеспечения.

Разработка организована с использованием Jira и GitHub
и разделена на два спринта.

## Планируемые возможности

- Случайный выбор загаданного слова.
- Отображение неотгаданных букв.
- Проверка введённых букв.
- Подсчёт оставшихся попыток.
- Определение победы и поражения.
- Возможность повторной игры.
- ASCII-визуализация виселицы.

## Используемые технологии

- Python 3.12
- Git
- Jira
- Doxygen

## Статус проекта

Реализован рабочий прототип игры
